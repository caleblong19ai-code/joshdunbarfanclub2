# Josh Dunbar Fanclub V2

Development/staging repository for the V2 redesign of joshdunbarfanclub.com.

Current interactive systems include the responsive Bean Run field trial (`game.html`) and Bean Galaga (`beangalaga.html`). The legacy `game-mobile.html` URL redirects to the canonical responsive Bean Run implementation.

Production remains `Big-JoshD/joshdunbarfanclub` until the redesign is reviewed and promoted.

For current staging state, verified gameplay milestone, production boundary, and next actions, read `PROJECT-STATE.md` before making changes.
